# Security and privacy

Do not include cookies, browser profiles, message logs, captures, or real conversation text in issues or pull requests. Reproduce problems with synthetic IDs and messages.

This server controls a logged-in browser and can send messages, edit messages, and react to profiles. Keep it local and grant client access only to trusted users. Do not expose stdio through an unauthenticated network bridge.

Message text is recorded locally by default. Review README data locations and retention instructions before use. Request IDs only suppress duplicate attempts within one server process.

Report vulnerabilities privately to the repository owner through GitHub's private vulnerability reporting if enabled. Otherwise contact the owner privately; do not disclose credentials in a public issue.
